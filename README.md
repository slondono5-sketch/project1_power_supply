## 📌 Descripción

Fuente de laboratorio que convierte la tensión AC de un transformador en cinco salidas DC reguladas, mediante rectificación con puente de diodos, filtrado capacitivo y convertidores DC/DC integrados en la PCB.

## 🔌 Salidas

| Salida | Corriente máx. |
|:---:|:---:|
| **+12 V** | 5 A |
| **+5 V** | 5 A |
| **+3.3 V** | 3 A |
| **−12 V** | 1 A |
| **1.25 – 15 V** | 3 A |
